# Contribution heatmap

The repository includes a lightweight static GitHub-style contribution heatmap. The workflow fetches public contribution counts for `gptshivam595`, validates the calendar, writes `site/contributions.json`, refreshes the README preview, and deploys the interactive page to GitHub Pages.

The page is intentionally dependency-free. It renders the calendar with Canvas, supports responsive sizing, hover details, and keyboard navigation, and keeps the summary statistics tied to the same fetched data.
